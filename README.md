# Jsp_Menz - 남성 쇼핑몰 웹사이트


✨ 주요 기능

🧑‍🤝‍🧑 회원 관리: 회원가입, 로그인, 회원 정보 수정 및 탈퇴

🛒 장바구니 & 주문: 상품 선택, 장바구니 담기, 결제 및 주문 내역 확인

<br>

## 🏁 시작하기

### 1️⃣ 필수 소프트웨어 설치

Node.js
Git

### 2️⃣ 프로젝트 클론

git clone <깃허브-프로젝트-URL>

### 3️⃣ 백엔드 서버 설정 (/server)

1.필요한 라이브러리 설치
비주얼 스튜디오 터미널에 명령어 입력 
터미널 오픈 : ctrl + ~

npm install express
npm install cors

2.서버 실행

cd server
node server.js -> ✅ 서버 실행 중: http://localhost:3000 클릭
